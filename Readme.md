# Эмулятор учебного процессора
Данный проект представляет собой эмулятор учебной вычислительной машины, построенной только на АЛУ, ОЗУ, регистрах OUT, IR, MAR, MDR, AC, PC и флагах CF, ZF и SF.

## Характеристики
- Архитектура: Гарвардская, одноадресная. Это подразумевает раздельное хранение кода и данных в памяти и использование одного адреса в машинных командах;
- Длина машинного слова: 32 бит = 4 байта;
- Длина адреса в машинном слове: 16 бит = 2 байта;
- Тактовая частота: от 1 до 60 Гц, настраивается с помощью переключателя;
- Объем ОЗУ: 65 536 ячеек, каждая по 4 байта = 256 КБ;

## Функционал
- Два режима работы процессора:
  - последовательное выполнение всей программы,
  - выполнение программы по шагам;
- Возможность написания ассемблерного кода прямо в эмуляторе;
- Отображение изменения состояния ОЗУ, регистров и флагов в реальном времени;
- Отображение сведений о текущей исполняемой команде;
- Панель ОЗУ с возможностью редактирования ячеек;
- Панель логов работы эмулятора.
