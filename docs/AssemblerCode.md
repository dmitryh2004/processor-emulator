# Ассемблерный код
Это шпаргалка по ассемблерному коду [учебного процессора](../Readme.md).

## Операторы
В ассемблере реализованы 16 операторов:

| Операции | Номер | Формула |
| :--- | :--- | :--- |
| MOV | 0 | `C <- A` |
| INC | 1 | `C <- A+1` |
| ADD | 2 | `C <- B+A` |
| JC | 3 | `CF? PC <- C` |
| JNE | 4 | `~ZF? PC <- C` |
| JL | 5 | `SF? PC <- C` |
| JG | 6 | `~SF? PC <- C` |
| JE | 7 | `ZF? PC <- C` |
| MUL | 8 | `C <- A*B` |
| DIV | 9 | `C <- A/B` |
| OR | a | `C <- A\|B` |
| NOT | b | `C <- ~A` |
| JNC | c | `~CF? PC <- C` |
| SUB | d | `C <- A-B` |
| DEC | e | `C <- A-1` |
| AND | f | `C <- A&B` |

## Команды
На основе операторов создано 19 команд:

| Команда | Формула | Пример записи | Пояснение к примеру |
| :--- | :--- | :--- | :--- |
| LOAD Q | `AC <- Q` | `LOAD 0x1c` | Загружает данные из ячейки памяти №29 в AC |
| STOR Q | `Q <- AC` | `STOR 0x10` | Загружает данные в ячейку памяти №16 из AC |
| ADD Q | `AC <- AC+Q` | `ADD 0x4` | Прибавляет к AC значение из ячейки памяти №4 |
| JC Q | `(CF)? PC <- Q` | `JC 0x1` | Прыгает на 1 строку, если поднят CF |
| INC Q | `AC <- Q+1` | `INC AC` | Увеличивает АС на 1 и записывает его в АС |
| SUB Q | `AC <- AC-Q` | `SUB 0x10` | Вычитает из АС значение из ячейки памяти №16 |
| JNC Q | `(~CF)? PC <- Q` | `JNC 0x1` | Прыгает на 1 строку, если НЕ поднят CF |
| DEC Q | `AC <- Q-1` | `DEC 0x1` | Записывает в АС значение из ячейки памяти №1, уменьшенное на 1 |
| MUL Q | `AC <- AC*Q` | `MUL AC` | Умножает АС на AC |
| DIV Q | `AC <- AC/Q` | `DIV 0x2` | Делит АС на значение из ячейки памяти №2 |
| AND Q | `AC <- AC&Q` | `AND 0x4` | Побитовое И с АС по значению ячейки памяти №4 |
| OR Q | `AC <- AC\|Q` | `OR 0x3` | Побитовое ИЛИ с АС по значению ячейки памяти №3 |
| NOT Q | `AC <- ~Q` | `NOT 0x2` | Побитово инвертирует значение ячейки памяти №2 и записывает его в АС |
| JMP Q | `PC <- Q` | `JMP 0x0` | Безусловно прыгает в начало кода |
| JE Q | `(ZF)? PC <- Q` | `JE 0x1c` | Прыгает на 29 строку, если поднят ZF |
| JL Q | `(SF)? PC <- Q` | `JL 0x7` | Прыгает на 7 строку если поднят SF |
| JG Q | `(~SF)? PC <- Q` | `JG 0xa` | Прыгает на 10 строку если НЕ поднят SF |
| JNE Q | `(~ZF)? PC <- Q` | `JNE 0x0` | Прыгает на 0 строку если НЕ поднят ZF |
| CLS | `AC <- 0x0` | `CLS` | Обнуляет значение АС резервированным нулем из ячейки №0 |

## Комментарии
Комментарии отделяются от кода программы точкой с запятой (;) и являются однострочными. Компилятор ассемблера игнорирует все символы между точкой с запятой (включая ее саму) и переносом строки/концом кода.

## Типы данных
Процессор оперирует только целыми 32-разрядными числами. 
> Числа с плавающей запятой, а также целые числа большей разрядности нативно не поддерживаются и должны быть реализованы разработчиком самостоятельно при необходимости.
